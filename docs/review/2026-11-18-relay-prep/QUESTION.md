# 교차 검토 요청: relay auto 사전 조건·시간 상한·교체 실패 문구

검토 대상: 같은 폴더의 `CHANGES.diff`(git diff, 7개 파일). 저장소 루트는 이 폴더의 두 단계 위다.

배경
- relay auto는 사람 없이 단위를 반복하는 실행 모드다. 실제 시범에서 세 가지가 드러났다.
  1. 시간 상한이 사람을 기다린 시간까지 세서 두 번 멈췄다.
  2. 새 세션이 "trust this folder" 확인 창에서 멈춰 세션 교체가 실패했는데, 실패 문구에 이유가 없었다.
  3. 사용자 지시: "auto면 폴더 신뢰, 모든 bash 명령을 전체 허용으로 하고 진행해야 해."
- 변경: 중단 동안 시간 정지(`stopped_at`·`paused_sec`), rotate.sh 실패 문구에 상태 사유, check에 사전 조건 2개(폴더 신뢰 읽기 전용, 프로젝트 `.claude/settings.local.json`의 `permissions.allow`에 `"Bash"`), 새 하위 명령 `prep`(Bash 허용을 넣고 인계 문서에 기록)·`unprep`(prep가 넣은 것만 지움). 사용자 확인 1회 뒤에 prep를 실행하고, 완료 때 unprep를 실행한다.

판정 기준
1. 권한 경계: prep·unprep가 사용자가 원래 둔 설정을 지우거나 덮을 수 있나? 기록 없이 허용이 남는 경로가 있나? `~/.claude.json`을 쓰는 경로가 있나?
2. 실패 시 안전: 파일 손상(원자적 쓰기), 잘못된 JSON, 동시 실행, 중간에 끊김.
3. 시간 계산: 중단·재개가 반복될 때 elapsed가 맞나? 옛 state.json 호환.
4. 시험이 위 결함을 실제로 잡나?
5. 뺄 것: 지워도 되는 장치·시험·절차 1개 이상. 없으면 "없음".

답 형식(한국어)
- 판정: PASS 또는 FAIL
- 지적: 번호, 등급(필수 수정/이번 개선/후속 제안), file:line, 문제, 재현 또는 근거
- 뺄 것
