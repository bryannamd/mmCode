## 1회차

| 검수 | 판정 | 지적 |
|---|---|---|
| 코드 | PASS(필수 수정 0건) | 후속 제안 2건: 이벤트가 없는 단위는 보드에 나오지 않는다. 멈춤 이유가 문자열이 아니면 그리기가 멈춘다. 뺄 것: 쓰지 않는 `PHASE_KO` 내보내기 |
| UI | 검수자 PASS(이번 개선 3건). 계획자가 캡처에서 결함 1건을 더 찾아 실패로 기록했다 | 멈춘 단위가 360px 첫 화면 밖에 있다. 읽은 곳과 시각 표시가 없다. 같은 파일을 다시 고르면 읽히지 않는다. `blocked:<단위>`를 "<단위> 끝나길 기다림"으로 잘못 설명한다(계획자) |

조치: UI 검수 실패를 기록하니 `move B1 done`이 거부됐다(`REFUSED: B1 에 빠진 증거: mutation, ui-review`). `move B1 build --reason`으로 되돌려 일꾼이 5건을 고쳤다(재위임 1회).
